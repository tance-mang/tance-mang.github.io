How this site works

零构建静态站点：文章就是仓库里的 HTML 文件，GitHub Pages 直接部署分支根目录，没有数据库、没有服务端渲染。

首页的精选文章、思维星图、演化时间线、思想碎片、主题索引与搜索结果，都由浏览器在运行时从 create.html、observe.html 和 archives/index.html 汇总而来。新增一篇文章只需要出现在它所属的列表里，其他区块自动跟着更新。

Auto Blog Agent 负责自动写作与发布：它用 GitHub API 在一次提交里同时写入文章与两处导航列表。这条链路是本站设计的一条硬约束——任何改版都不能破坏它的占位符与插入标记。发布状态与未完成联调的部分在项目页如实列出。

实时信号区读取 GitHub 公开事件 API；拉取失败时自动显示最后核实的快照并标注原因，不伪造在线状态。
