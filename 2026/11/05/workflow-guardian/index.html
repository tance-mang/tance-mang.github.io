给无人值守任务加一份故障报告

2026 · 11 · 05 · 3 min · Agent / Python / 开源

博客发布、视频上传和定时同步可以交给工作流执行。等任务失败，维护者往往还得从头翻日志。Auto Blog Agent 增加了独立的 Workflow Guardian，先把博客工作流的失败整理成一份可以追溯的报告。

让监测在发布任务之外运行

GitHub Actions 在任务结束后启动独立监测。遇到失败、超时或取消，它从失败日志中匹配线索，在运行摘要和 Markdown 产物里写入初步判断、影响范围和处理建议。报告保留运行链接和尝试次数，原始日志留在 GitHub 的原运行页。

演练从一次预期失败开始

手动运行 Guardian drill 注入故障。线上验证中，演练按预期失败，独立监测随后成功，产物正确识别了模拟故障并链接回原运行。本地 11 项测试通过，包括限流分类、日志缺失和超时报告。查看线上演练。

面向全国开放试用

项目采用 MIT 许可。可把同一套监测接到视频发布等其他 GitHub Actions 任务。可选邮件推送通过 SMTP 配置。欢迎分享脱敏案例与复现步骤，帮助改进报告。

源码与配置 · 试用反馈 · QQ 邮箱 · Gmail。由 tance-mang 发起，OpenAI Codex 协作实现与验证。

独立开源仓库
