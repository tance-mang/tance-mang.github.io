背景

内容研究需要把分散的互动数据、评论需求和产品资料放进一个可查的地方，而不是散在表格和截图里。

问题

既要避免爬取与平台接口依赖，又想让本地数据能被统计、被 AI 使用，同时数据不出本机。

技术实现

  • 授权后的 CSV / Excel 导入本地 SQLite，互动评分与图表在本地完成。
  • 评论摘要进入本地规则统计，不上传原始数据。
  • 通过自己的 AI 服务（含本地 Ollama）生成待审核文案，人工确认后才使用。
  • 平台名称只用于数据分类与提示词场景，README 明确说明这不代表官方接口接入。

实际验证

  • README 提供完整的本地流程图与目录结构，源码公开供学习与个人使用。

局限与未完成

  • 采用限制商业分发的自定义许可，并非 OSI 标准开源许可。
  • 仅作者或获得书面授权的销售者可以销售软件。
  • Windows 本地工具，不含服务端部署方案。
