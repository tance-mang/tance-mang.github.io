背景

用大模型写中文网文时，大多数人在做的是零散复制 prompt：今天一个开篇模板，明天一个爽点清单，规则互相冲突，也不懂平台与读者的商业逻辑。

问题

需要一套稳定、可组合、懂网文行业约束的工具：男频女频双线、起点 / 番茄 / 晋江 / UC / 知乎盐选 / Webnovel 的平台差异、同人合规、以及最容易翻车的 AI 味。

技术实现

  • 39 个技能按流程串联：选题 → 灵感 → 大纲 → 黄金开篇 → 金手指 → 人设 → 正文扩写 → 爽点打脸 → 节奏标注 → 追读诊断 → 去 AI 味 → 投稿过稿 → 平台趋势。
  • 35 份参考库把题材、平台与合规要求写成可查资料，而不是塞进单条 prompt。
  • 英文写作拆成 original / adapt / translate 三条路径，节奏按类型调整，配双语档案。
  • CLI 支持命名模型配置、兼容 Chat Completions、本地 Ollama、健康检查与显式切换。
  • 海外投稿资料标注官方来源与核验状态，未核实的政策继续标为待核。

实际验证

  • CHANGELOG 记录到 0.29.1（2026-06-13），并保持语义化版本。
  • 仓库当前有 104 个 star 与 17 个 fork，可在 GitHub 上直接核对。
  • 离线测试与文件交接流程在 CHANGELOG 中有逐项记录。

局限与未完成

  • [Unreleased] 中仍有进行中的改动，技能覆盖不等于成稿质量保证。
  • 平台政策会变化，参考库里的核验状态需要按时间重新检查。
  • 输出仍需作者逐段判断，工具不做自动投稿。
