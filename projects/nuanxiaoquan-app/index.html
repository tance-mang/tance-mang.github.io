背景

记账、生理期记录和学习计划通常是三个互不相干的 App。但真正想知道的恰恰是它们之间的关系：这个阶段的消费变化、经期前后的学习状态。

问题

把三件事放进同一个应用不难，难的是建立关联而不牺牲离线可用性，也不把敏感数据交给云端模型。

技术实现

  • 统计、预测、状态判定全部由本地确定性算法完成，AI 只承担文案生成，断网不降级。
  • 三者之间建立关联：经前期高消费提醒、经期学习降档、月度三维复盘。
  • Android / iOS / Web 三端，服务端为 Spring Boot。
  • 仓库 README 单独写了安全设计（网络空间安全维度）与离线能力矩阵。
  • 已完成 ICP 备案（桂ICP备2026007360号-2A）。

实际验证

  • README 记录了版本号 1.1 与离线能力矩阵。
  • 备案信息为真实公开记录。

局限与未完成

  • 最近一次推送停在 2026-05-22，当前处于暂停迭代状态。
  • 公开仓库为源码存档，完整工程与线上服务不在本仓库内。
