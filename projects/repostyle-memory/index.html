背景

让 AI 开发完项目之后，还要反复解释 README 怎么写、测试怎么记、简介怎么介绍。每一次换工具都要重新交代一遍。

问题

这些要求属于个人规范，不属于任何模型或工具。需要一种可迁移、有据可查的存放方式。

技术实现

  • 流程：个人规范 → 仓库识别 → 变更证据 → 文档增量更新 → 真实测试记录。
  • 规则以文件形式存放在仓库中，任何能读取本地文件的 AI 编程工具都可以直接使用。
  • 强调保留变更依据：改了什么、为什么改、依据是什么。

实际验证

  • 提供简体中文与英文两份 README，安装方式为直接 clone 技能仓库。

局限与未完成

  • 输出仍取决于宿主模型的遵循能力，规则文件不替代人工校对。

版本记录

该仓库没有独立的版本号记录，迭代过程保存在提交历史与 README 中。
