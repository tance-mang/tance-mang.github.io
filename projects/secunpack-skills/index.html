背景

安全入门资料常见两种极端：只讲概念，或者直接给攻击工具。前者学完无法验证，后者跳过机制去追求结果。

问题

需要一条固定流程：先理解机制，再在本机观察证据，最后验证防御是否真的起作用——而且整条路径不能依赖扫描公网或运行恶意样本。

技术实现

  • 固定教学流程：场景 → 通俗解释 → 技术机制 → 安全实验 → 证据观察 → 防御验证 → 独立挑战 → 学习记录。
  • 两个本机实验：一个观察进程、文件与回环网络行为；一个是故意保留脆弱页面的 Web 教学应用，用来对比 SQL 拼接与参数化查询、未编码输出与转义输出。
  • 两套实验均只使用 Python 标准库，核心 Skills 为 Markdown，可被不同模型与 Agent 宿主复用。
  • Web 教学应用只允许本机回环访问。

实际验证

  • 当前版本 v0.2.0，新增 Web 安全学习路径。
  • README 明确列出「这不是什么」：不是杀毒软件、EDR、漏洞扫描器或自动渗透工具，不分析真实恶意软件，不扫描公网、不提权、不持久化、不关闭安全软件。

局限与未完成

  • 文档当前为中文，稳定后再补英文。
  • 不同 AI 客户端能否自动加载 Skills 取决于宿主，不支持时需要手动提供 SKILL.md。
  • 不保证每个模型都按同一流程执行。
