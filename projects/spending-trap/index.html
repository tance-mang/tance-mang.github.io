背景

消费心理的机制写在文章里很难被感受到。想做一个让玩家先体验、后发现的场景：小额消费、促销优惠和预算取舍都发生在具体情境中。

问题

如果直接把金额和余额摆在界面上，玩家会进入计算模式，机制感就消失了。设计难点是让玩家通过自己的决定逐渐意识到环境如何影响选择。

技术实现

  • 从四幕线性流程重构为自由探索的心愿街，再推进到全屏第一人称叙事。
  • 店铺热区移除可见边框，改为环境光晕悬浮反馈，四色对应四家店铺。
  • 隐性消费累积：购物袋只显示件数不显示金额，顶部栏移除现金余额。
  • 街区加入四位独立行人，步幅随行走距离推进，形成前景层次与纵深。
  • 油画场景资产保持 800:457 比例，桌面端不放大；UI 由代码驱动而非绘制在背景里。

实际验证

  • README 中有 v1 到 v6 的完整迭代记录，当前版本为 v6（首页与街区收纳布局）。
